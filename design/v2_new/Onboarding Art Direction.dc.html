Art direction — proposal, revision 2
Stop showing the UI. Show the idea.
Every current hero is a miniature app screenshot — a request card, three list rows, floating pins. That is the single reason it reads as a prototype. All four are replaced with diagrams and typography.
Revision 2 — the ring is now literally one object
Rev 1 drew four similar-looking ring sets and called them one. Now every frame renders the same three rings — base diameters 216 / 152 / 107 (fixed 1.42 ratio), fixed centre (252, 300), scaled by 1.00 → 1.24 → 1.62 → 0.90. Count, centre and ratio never change; only scale and opacity do, which is exactly what the approved motion system can produce. Mid frames sit at the interpolated scale with the ring's 0.15× parallax applied.
Frames are 390×844. Interaction architecture unchanged — composition only.
