How it stays guided rather than becoming a form
Answered
Collapses to a one-line summary with a green check. Values stay in Newsreader so they read as facts, not fields. Editable in place — no back navigation.
Live
Exactly one question is expanded at a time, marked by a red ring and a red micro-label. Its options are full-size rows — the same selected-state inversion as A.
Pre-filled
Location arrives from GPS already correct, collapsed behind a chevron. Present and checkable, but never blocking. Answering urgency expands nothing further.
Both directions use the identical grammar — cream ground, hairline section rules, uppercase micro-labels, bordered option rows inverting to a solid red field when selected, one fixed primary CTA, no cards anywhere. The approved direction differs only in that the sequence is vertical rather than temporal. Across all three location states, the composition above the live question never changes — which is what makes a permission failure feel like the next question rather than a fault.
