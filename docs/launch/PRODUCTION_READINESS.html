  • Read a card. Tap one button on it: Do it (go with my suggestion), Done (you already finished it), Later, Skip, or Change (write your own answer in the box).

  • Test cards at the bottom: Pass or Fail, and write what you saw in the box.
  • When you finish (or want to stop), press Copy my decisions at the top, then paste the whole text into the chat with me. Your choices are saved in this browser, so you can close the page and come back. Use the same browser and the same file.
  • Short on time? Press Key decisions in the filter bar. Those are the 13 that change what I build.

Already checked and fine (no action)

  • Target Android is API 36 (Play's current rule). Minimum is Android 7.
  • 16 KB memory-page support: every arm64 native library is aligned (zip and ELF both checked).
  • No risky permissions: no background location, call log, SMS, contacts, storage, advertising ID or full-screen intent.
  • Android 14 phone-call permissions are present (FOREGROUND_SERVICE_PHONE_CALL, MANAGE_OWN_CALLS, microphone type).
  • The four notification channels are created at launch. Dead push tokens are removed automatically.
  • Accepting a request is one transaction: only one donor wins, and the database rules check it again. Donation needs both people to confirm.
  • Phone numbers are never copied onto requests. 14 Cloud Functions and the Worker are live. Last test runs: 97 app tests, 26 Worker tests.
